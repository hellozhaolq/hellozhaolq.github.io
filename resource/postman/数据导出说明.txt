
Workspace 数据导出：
    1、右上角，Settings → Account Settings，会进入浏览器页面。
    2、进入 Export Data 页面，点击 Export Data，全选后点击 Request data export，等待【请求数据导出】状态变为 Completed。
    3、Postman 会把全部数据打包成一个 ZIP 压缩包，随后发一封包含下载链接的邮件到你的注册邮箱里

Workspace 数据导入：
    右上角，File → Import...



Globals 必须单独导出：
    Postman 官方对 Globals 的定义是跨所有 Workspace（工作空间）的超全局本地变量。而 Data Dump 导出的主要是各个工作空间里的资产（Collections 和 Environments）。
Globals 弃用：
    因为绝大多数其他 API 工具（比如 Bruno）在导入 Postman 数据时，不认 Global 文件，或者对 Global 的兼容性极差。它们基本都支持普通的 Environment JSON 文件。
