# 通用问题

这5个问题几乎适用于大多数研发岗位，建议根据面试官身份选 2～3 个即可。

1. **业务职责：**对于这个岗位，入职后主要负责哪些业务模块？前期最需要承接的核心工作是什么？
2. **技术挑战**：目前团队在技术（或业务）上面临的最大挑战是什么？未来的有哪些重点优化方向？
3. 阶段期望：对于这个岗位的新人，您希望他在前 3 个月完成哪些成果？怎样算是符合预期？
4. **匹配度**：结合刚才的交流，您觉得我的技术背景和经验与这个岗位是否匹配？
   您觉得我还有哪方面能力需要补齐才能更匹配？（这个问题很容易获得真实反馈！）
5. 后续流程：请问接下来的面试流程和大概的反馈时间是怎样安排的？
