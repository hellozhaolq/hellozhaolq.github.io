Clash Verge 配置优先级

Clash Verge 在处理流量时，各类扩展脚本和配置的加载优先级如下：

  1. 全局扩展覆写配置（最高优先级）
  2. 全局扩展脚本
  3. 订阅扩展覆写配置
  4. 订阅扩展脚本（最低优先级）

提示：全局扩展配置 和 全局扩展脚本 会作用于所有订阅 Profile，适合放置公司内网分流、本地 DNS 覆盖等通用固定需求。

前置路由规则

作用： Clash 的路由规则将按照从上到下的顺序匹配，列表顶部的规则优先级高于其底下的规则。通过 JavaScript 脚本将自定义规则动态插入到规则列表的最上方，可确保关键请求直接命中，不触发后续订阅自带的规则。

应用场景： 防止通用的地理位置规则（如 GEOIP,CN）或兜底规则（如 MATCH,Proxy）误拦截内网流量，导致局域网 域名 或 IP 误走代理。

Fake-IP 技术（伪造 IP 技术）是一种在网络代理（尤其是透明代理）中广泛使用的 DNS 解析优化方案。其核心逻辑是：当客户端发起 DNS 查询时，本地代理软件不向远程 DNS 服务器查询真实 IP，而是直接从预设的私有 IP 池中分配一个“虚假”的 IP 地址并立即返回给客户端。同时，代理软件在本地维护一张 Fake-IP 与真实域名的映射表。

dns.nameserver-policy

作用： 指定 DNS 服务器。该配置支持 geosite 语法，且优先级高于普通的 nameserver 与 fallback 查询。

应用场景： 强制让国内常见域名和公司内网域名使用 **系统默认 DNS（system）**进行解析，防止内网域名被发送至远程 DNS 导致解析失败或泄露。
