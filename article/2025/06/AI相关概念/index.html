大模型

Prompt：写好提示词，用好 AI 工具。

模型不会因为你的对话而”学习”或”变聪明”。它的知识截止于训练完成的那一刻。

大模型通常采用两阶段训练：

  • 预训练：在海量数据上学习通识。是最花钱的部分：数据多、算力大、时间长。
  • 微调：针对特定任务优化。用很少的高质量数据进一步训练模型。

预训练让模型有知识，微调让模型好用。

模型蒸馏：大模型训练小模型。让小模型尽量学到大模型的能力，蒸馏后的模型体积更小、推理更快、部署成本更低。

LLM 原生是失忆的——每一次对话都是全新的，除非你把上下文塞进去。

RAG 检索增强生成

RAG（Retrieval-Augmented Generation，检索增强生成）是一种让大语言模型基于特定知识库回答问题的技术。

RAG 分为两个阶段：离线索引阶段和在线检索阶段。

AI Agent

AI Agent（智能体）是一个能感知环境、做出决策、采取行动的自主系统。

Agent 的基本架构：

  • 大脑：LLM 作为推理核心
  • 工具：扩展 AI 的能力边界
  • 记忆：短期 vs 长期记忆
  • 规划：任务分解

工具调用是 Agent 最基础也是最重要的能力。

ReAct 规划循环：ReAct 这个名字来自 Reasoning（推理）和 Acting（行动）的结合。核心思想：让 Agent 像人一样，想一步、做一步、看一看，然后重复这个循环，直到任务完成。

记忆系统设计：

  • 对话历史：短期记忆
  • 向量数据库：长期记忆
  • 摘要压缩记忆

主流 Agent 框架：

  • LangChain Agents
  • LlamaIndex Agents
  • AutoGPT
  • CrewAI 多智能体：思路是让多个 Agent 组队协作

多模态 AI

模态（Modality）指的是信息的表现形式。文字、图片、音频、视频，这些都是不同的模态。

多模态 AI 的核心突破是：它能把不同模态的信息转换成同一种语言来理解。

AI 工作流自动化

AI 工作流是把多个 AI 能力和工具串联起来，形成一个自动化流程。
